# 拾字界面规范（草案）

2026-10-10 起草，等用户定。管的是「拾字」App 的界面。数值没写到的，用系统控件的默认样子。

## 0. 一句话主张

**拾字把图里的字拾出来。** 界面的主角是认出来的字，和它在原图上的位置：打开就能拖、能粘贴，认完能复制、能导出，
认不准的地方标出来给人看。判定插件、接入灵犀这些是旁路，放在设置里，平时不抢眼。

## 1. 跟灵犀共用的规矩

照《灵犀桌面端设计规范 v2》（灵犀是作者自己的 AI 助手，仓库不公开，这里只摘用到的）的设计主张（安静、先组合后发明、
桌面习惯优先、状态全应用一个样、反馈要真实）、§8 状态与反馈、§10 界面用词、§11 桌面习惯。

拾字是原生 App，**数值不照搬灵犀的网页档位**：字号、控件高、圆角用系统的，跟 macOS 自己的 App 一个样。为什么：
用户在 Mac 上练了多年的手感是系统控件给的，自己画一套反而像网页。

## 2. 档位

| 类 | 档位 | 用在哪 |
| --- | --- | --- |
| 字 | 系统字体；文字样式 `.title3`、`.headline`、`.body`、`.callout`、`.caption` | 页头标题、分组标题、正文和认出的字、说明、页码和次要信息 |
| 字重 | 常规、中等（`.medium`）、粗（`.semibold`） | 中等只给列表里的名字；粗只给页头标题 |
| 间距 | 4、8、12、16、24 | 控件内部、相关控件、同一组、不同组、不同区 |
| 圆角 | 6、10 | 框选和小块、大块（跟窗口一样） |
| 线 | 1 像素，系统分隔线颜色 | 分区 |

不写裸字号。等宽字只给表格和代码。

## 3. 颜色

- 灰：系统的主要、次要、最淡三级文字色；底色、分隔线都用系统的。深色模式跟着系统走，不自己配。
- 强调色（系统强调色）只做三件事：选中的行和框、正在识别的进度、空状态里唯一的主按钮。
- 「可能认错」用琥珀（系统橙），不呼吸；出错用红。两种都不能只靠颜色：旁边要有图标和字。
- 原图上的框：平时细灰线；选中的那一行用强调色描边加淡底；可能认错的用琥珀虚线。框能关（工具栏开关、「显示 › 显示识别框」⇧⌘B，
  默认开），关了只画选中的那一行。

## 4. 布局

- 左栏：这次打开过的文件（打开过才有这一节），和「照片」的相簿（没给照片权限时只有一行「照片图库」）。
- 右边是文件时：页头（文件名、页数、状态、操作）；下面左边是原图（多页时最左边一条窄的页码栏），右边是认出的字（整页 / 逐行）。
  整页 / 逐行在页头工具栏上切（分段控件，排在操作按钮前面），像访达切换显示方式；不在字那一栏顶上单占一条（那样像网页的标签页）。
- 多页的原图那一栏连续滚动（照「预览」默认的样子）：所有页上下接成一长条，一页最多放满一屏（宽、高都放得下，整页看得见，小图不放大），
  页与页之间空 16；鼠标、触控板都跟着手走。页码栏、右边的字跟着可见的页换，滚到头、尾时一定对应第一页、最后一页。
  通常看视口中部；首尾的短页到不了中线时，只在这一小段滚动里调整判断位置，不能漏掉首尾。
  点页码栏按同一套位置跳过去（能居中就居中，不带动画）；点原图上的字只选页和行，不把已经在眼前的页挪走。
  这次打开的文件切走再回来、窗口改变大小后，都保留当前页；整份文件一屏放得下时，保留手动选中的页。
  还没画好的页先拿缩略图顶着，缩略图也没有就是一张白纸加个小转圈；替换高清图、文字识别进度更新时不挪动原图。
- 右边是相簿时：页头（相簿名、认到什么程度、「识别」）；下面是照片网格，方格、圆角 6、间距 8。相簿不像文件那样一打开就认（可能几百张、要下载），
  所以「识别」带字，是这里唯一的主要操作。
- 搜照片：相簿页顶上的搜索框，搜的是认过的全部照片（不只这个相簿）。结果一张一行：缩略图（56 点、圆角 6）、文件名（中等字重）、
  拍摄时间（`.caption` 次要灰，写成 2026-10-02 16:00，跟 photos_search 一样）、字里搜到的那一段（`.callout`，搜的词主色、其余次要灰，
  不另加颜色、不加粗）。没搜到时页头那句不说，中间说一次。
- 点开一张照片：在相簿那一栏里推上来（照「照片」App），跟文件一个看法；左上角「‹」回网格，滚到哪、选了哪张都还在。
  页头标题是文件名，下面「第 3 / 78 张」；上一张、下一张用上下箭头（像「邮件」翻信，免得跟左上角的返回混了）。
  看的照片不进左栏：左栏只放自己带进来的文件和相簿。
- 分类：页头「分类」开一小窗。顶上两个分段控件并排：看什么（看认出的字 / 看画面）、怎么分（按类别分 / 按一句条件找）；下面写明发什么
  （认出的字，或缩到 360 像素的照片）、发到哪。看字、看画面写的类别各记各的，切过去写的还在。分过类的相簿，网格上面一排筛选：全部、每一类、
  待确认、没有字（只有看字时有），各带张数；选中的用强调色，0 张的灰掉；选了一类右边「存为相簿…」（默认名「拾字 · 类别」）。
- 窗口变窄时：先把字那一栏收到最小宽，再收左栏；整个窗口不滚，只让原图和字各自滚。

## 5. 状态

| 状态 | 样子 |
| --- | --- |
| 识别中 | 页头一条细进度条，旁边「第 3 / 20 页」（次要灰）和「停止」；左栏这一行标题前一个小转圈 |
| 出错 | 红色感叹号加一句话：出了什么事、怎么办；一个「重试」 |
| 完成 | 不出声。左栏行尾只写页数 |
| 可能认错 | 逐行里行首一个琥珀的 ⚠︎ 加「可能认错」和原因；整页里不标（整页是给读和复制的）；原图上琥珀虚线框 |
| 判定插件看过的行 | 逐行里：插件认为认错的，照「可能认错」那样标，原因写「clef 认为认错了（约 90%）」；看过没问题的，下面一行次要灰「✓ clef 看过，没问题」 |
| 识别详情 | 页头的 ⓘ，点开一小块：这一页怎么认的（认法、拉正、小字、可能认错几行、用时）和判定插件做了什么；插件没用上也说为什么，不让人以为没装 |
| 照片的角标 | 只标要人留意的：原图在 iCloud 上没下下来（云）、出错（红色感叹号）、排着等下载（云加箭头）；认过的不标。悬停每格都有一句：认没认过、有没有字、没认成为什么 |

- 空状态：一句话说能干什么、怎么开始，一个主按钮「打开…」，下面一行次要字说也能拖进来、能粘贴截图。
- 认完不弹「成功」：字已经在眼前了。

## 6. 用词

照灵犀 §10。拾字自己的词：

| 东西 | 叫法 | 别叫 |
| --- | --- | --- |
| 动作 | 识别、重新识别、停止 | OCR、扫描、处理 |
| 结果 | 认出的字 | 识别结果、文本 |
| 可疑行 | 可能认错 | 低置信度、疑似错误 |
| 框一块认 | 框选识别 | 区域 OCR |
| 两种看法 | 整页、逐行 | 全文（「复制全文」说的是整个文件，别混） |
| 导出 | 导出…（会弹出存放位置） | 另存为结果 |

MCP 第一次出现时带一句白话：「让灵犀、Claude Code 这些助手也能用拾字认字」。

英文界面照 macOS 的习惯：按钮、菜单项、标签页名、窗口标题每个实词首字母大写（Save as Album…），表单标签、开关、悬停提示用句子式；
上面这些词的英文叫法跟着 `scripts/app/en.lproj/Localizable.strings` 里已有的走（认出的字 recognized text、可能认错 may be misrecognized、整页 / 逐行 Page / Lines）。
英文比中文长，改了界面中文、英文截图都要看，标签、按钮别被截断。语言的名字（简体中文、English）照它自己的写法，不跟着界面翻。

## 7. 桌面习惯

- ⌘O 打开，⌘V 粘贴截图，⌘C 复制选中的字，⇧⌘C 复制全文（整个文件），⌘E 导出 Markdown…，⌘R 重新识别，⌘. 停止。
- 「显示」菜单最上面：整页 ⌘1、逐行 ⌘2（跟工具栏上的是同一个设置），没在看文件或照片时灰掉。
- 照片：⌘R 识别这个相簿，双击或回车点开一张，⌘A 全选，Esc 或点空处不选，⌘ 点加选。
- 点开的照片：← → 翻张，Esc 或 ⌘[ 回网格，⌘R 重新识别这一张。
- 照片的右键菜单：打开、加进相簿。右键点在选中的那几张上，对选中的几张做；点在没选中的一张上，只对这一张做。
  「加进相簿」页头也有，选了照片才出来。
- 文件能拖进窗口，也能拖到 Dock 上的图标。
- 逐行里每一行有右键菜单（复制这一行）；关键操作不藏在悬停里。

## 8. 设置窗口

三个标签：识别（含「照片」一组，最下面「界面」一组选界面语言）、判定插件、接入；宽 650，每页高度跟着内容走。「关于」用系统自带的关于窗口（菜单「拾字 › 关于拾字」）。
照「系统设置」：分组表单、左标签右控件；说明最多一句短的，细节放悬停提示。列表（判定插件、接入）一项一行：图标、名字、下面一行次要灰的现状，
右边一个开关或一个按钮；改用 ⓘ，删在右键；添加按钮放在列表下面右边。命令、路径这类长字不铺在页面上，放悬停提示或「在访达中显示」。
